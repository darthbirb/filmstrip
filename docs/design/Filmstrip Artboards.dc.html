The whole window, five times
The same interface at four sizes — wide with all three columns docked, narrow with the pane folded, the 640 × 480 minimum, everything at 200% — and then Settings over it. Nothing is laid out against a written-down breakpoint — each artboard shows what the frame does when it measures its own width against the columns' widths and the grid's 20rem minimum, and the pane folds first, navigation second, the grid never. Every size in these drawings is calc(var(--u) × n), where --u stands for 1rem: A, B, C and E set it to 16px, D sets it to 32px, and nothing else about D differs.
The library is src/dev/mock.ts — its sources, its folders, its filenames, its four shapes and its own gradient recipe for a thumbnail. Cairo's three items are all there are, so the grids here carry more of the same shapes to fill the window; nothing else is invented. Every decision from docs/design/BACKLOG.md is in these five windows as well as in the blocks below: the count pills, the folder disclosure and its counts, the picture on the panel, the action bar, the full-screen control, the indexing line above a footer that never moves, the failures banner, and the folded rail's own places.

Settings is a dialog over the window rather than a fourth column or a screen of its own. The frame is three columns and stays three columns; a preference set once a month should not cost the grid a permanent surface, and a dialog can be dismissed with Escape and leaves nothing behind.
01A rail, because this is going to get big. Tabs across the top hold six or seven names and then start scrolling; a rail down the side takes twenty, lets a section be called Tags and Aliases rather than Tags, and groups them under headings. The filter above it is how a person finds a row when there are eighty of them. Two rows are drawn because two are built; the shape is sized for the rest.
02The layout toggle now lives here, as a dropdown. It was the widest thing in the grid’s header — a header that has to hold the place’s name first — and it is set once and then left alone. Two glyphs were right in a toolbar, where the pictures beside them said what the choice did; in a list of preferences the choice has to name itself, so it reads Rows.
03Anything with a control on screen stays there. The tile size keeps its two steps in the grid’s header; whether the pane’s details are open is set by opening them, and it is remembered. A state you can set in place does not belong in a dialog — a second control for the same thing is a second thing to keep in sync, and it teaches people to go looking in the wrong place.
04There is no Save, and no help text. Every control writes as you touch it, 400ms after the last change, the way the panel widths already do — a dialog that can be cancelled implies a draft, and there is no draft. Each label is the shortest true name for the thing it sets; a settings row that needs a sentence is a row whose label is wrong.
The gear is in the window bar Left of the caption buttons, at caption-button width, so it belongs to the window rather than to any one column — the same reason search sits there. It is the only thing in the bar that is not Windows’ own furniture or the search field.
Left room, not drawn: sources, tags and aliases, triage hotkeys, trash limits. Each is a group in this dialog when the slice that builds it lands — which is why the groups are stacked and captioned rather than laid out as a fixed set.

The line cannot be moved; the band can wait above itA walk is watched — a number that climbs is read repeatedly, and a bar that jumps a row down mid-read loses the reader. Neither waits for the otherThe band does not hold the refusal back until the walk finishes, and the walk is not paused to say the folder was refused: they are about two different folders, and a message that arrives late about the wrong folder is worse than a foot two rows tall. Asking, then every sorting source — one here, because the library drawn above has one. Ticking the band's box picks a row here; choosing Ask Each Time is the only way back to the question. The kind is a setting, not a questionAsking at the moment of adding would mean a dialog after the picker's dialog, and asking a person to read two words — library and sorting — before they have seen either behave. So the doorway decides it, and this row is where it is corrected: the same segmented group a folder's status wears, at the row's right where a value belongs. Switching a source's kind moves its row between the Box and the tree and moves nothing on disk.
A source's row carries what only a source hasIts path, its count, its kind, and — when the drive is away — the word offline with the date it was last read, which is the one fact navigation's muted row cannot hold. An offline source keeps its remove button and loses its reveal: the folder is not there to open.
Renaming is the row, as everywhere elseA source's name is the app's own label for it, not the folder's name on disk, so it is edited in place — click the name and it is a field, the same way the pane's Name row works. That is why there is no rename button on the row: three glyph buttons where two will do is furniture.
The delete default lives with the sorting sources it namesDeleting a folder with files in it asks where they go, and with several sorting sources it asks which one — an answer a person gives the same way every time, so the band's box keeps it and this row holds it. It sits here rather than under Trash or Appearance because the choices in its menu are the rows above it: remove a sorting source and the default it held goes with it, and the row falls back to asking. It is the only setting in the app written by answering a question somewhere else, which is why the box in the band says so in words.
